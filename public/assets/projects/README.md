# Project images

Place project assets here and reference them from `content.json` with **site-root paths**, for example:

- Card cover: `/assets/projects/my-cover.jpg`
- Detail gallery: `/assets/projects/photo-01.jpg`

These files are served from `public/`, so URLs always start with `/assets/projects/…` (or include your Vite `base` prefix in production automatically via the app).
